# Documentación de traspaso

Escrita el 13 de octubre de 2026 para que otra persona u otro agente continúe el trabajo sin tener que redescubrir nada. Todo lo que aquí se afirma como hecho fue comprobado ejecutándolo o leyendo el código, y cada documento dice cuál de las dos. Lo que es opinión o hipótesis está marcado como tal.

| Documento | Para qué sirve |
|---|---|
| [TRASPASO.md](TRASPASO.md) | Empieza aquí. Estado actual, cómo levantar el entorno, mapa del código, decisiones y trampas. |
| [PAGINA-PUBLICA.md](PAGINA-PUBLICA.md) | Arquitectura, flujo, sistema de diseño y pruebas de las páginas públicas. |
| [HALLAZGOS-TECNICOS.md](HALLAZGOS-TECNICOS.md) | Auditoría del proyecto: seguridad, datos y calidad, con evidencia y estado de cada punto. |
| [NEGOCIO.md](NEGOCIO.md) | Por qué el proyecto no genera dinero, a quién venderle, cómo cobrar, reglas de negocio y riesgos legales. |
| [ROADMAP.md](ROADMAP.md) | Todas las funcionalidades posibles, evaluadas por valor, esfuerzo y riesgo, en orden recomendado. |

Los archivos `CLAUDE.md`, `.agents/AGENTS.md` y `.github/copilot-instructions.md` describen un stack que ya no es el real. La tabla correcta está en [TRASPASO.md](TRASPASO.md#2-stack-real).
